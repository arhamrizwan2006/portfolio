## 🌐 Overview

A single-page personal portfolio for **Muhammad Arham Rizwan** — BSRAI (Robotics & AI) student at the University of Lahore. Built entirely from scratch in one `index.html` file: no frameworks, no build step, just semantic HTML, custom-property-driven CSS, and vanilla JS for the interactive bits.

**Live:** [arhamrizwan2006.github.io/portfolio](https://arhamrizwan2006.github.io/portfolio/)

---

## 🎨 Design Philosophy

```
┌─────────────────────────────────────┐
│  Dark, Terminal-Inspired Aesthetic  │
│  ✅ Animated particle canvas bg     │
│  ✅ Typewriter-effect tagline       │
│  ✅ Scroll-reveal on every section  │
│  ✅ No frameworks, no dependencies  │
│  ✅ Fully responsive, mobile-first  │
└─────────────────────────────────────┘
```

Color palette: deep navy/black background (`#070710`), violet accent (`#6c63ff`), teal accent (`#00d4aa`). Typography: **Space Grotesk** for body/headings, **Space Mono** for code/terminal elements (Google Fonts CDN).

---

## 🧭 Sections

| Section | What's There |
|---|---|
| **Hero** | Name, animated typed-text role rotator, stats (semester, tech count, internships completed) |
| **About** | Bio, identity info-card grid, live terminal-style "whoami" widget |
| **Experience** | 3 completed internships — Code Room Hub (AI/ML), DecodeLabs (IoT), Neurofive Solutions (ML Fundamentals) |
| **Skills** | Robotics/AI focus + programming/tools, plus a tag cloud of technologies |
| **Projects** | 9 featured project cards, each linking out to its GitHub repo or live demo |
| **Contact** | Email, university, programme, location, GitHub, LinkedIn — plus a demo contact form |

---

## ⚙️ Tech Stack

| Technology | Purpose |
|---|---|
| **HTML5** | Semantic structure |
| **CSS3** | Custom properties, Grid/Flexbox, keyframe animations |
| **Vanilla JavaScript** | Particle canvas background, typewriter effect, `IntersectionObserver` scroll reveals |
| **Google Fonts** | Space Grotesk + Space Mono |
| **GitHub Pages** | Hosting |

No CSS/JS files — everything lives inline in `index.html` for a single-file deploy.

---

## ✨ Key Features

- 🌌 **Particle canvas background** — animated dots with proximity-based connecting lines
- ⌨️ **Typewriter hero tagline** — cycles through roles (Robotics & AI Student, Python Developer, ML Engineer, etc.)
- 📜 **Scroll-reveal animations** — sections fade/slide in via `IntersectionObserver`
- 🖥️ **Terminal widget** — mock `whoami` / `cat info.json` output in the About section
- 🃏 **Project cards** — hover-lift effect, direct links to repos and live demos
- 📱 **Mobile-first responsive layout** — nav collapses, grids stack on small screens
